# 图标素材（Crystal Studio）

本目录是 **GUI 版 exe 的唯一图标来源**，两个文件同一张图：

| 文件 | 尺寸 | 谁用 |
|---|---|---|
| `crystal-studio.ico` | **16 / 32 / 48 / 64 / 128 / 256** 六帧 | `crates/miredit-gui/build.rs` → `1 ICON` 资源 → 资源管理器 / 桌面 / 文件属性里的 exe 图标 |
| `crystal-studio.png` | 256×256 RGBA | `src/window.rs` → `include_bytes!` → `ViewportBuilder::with_icon` → 窗口 / 任务栏 / `Alt+Tab` 图标 |

⚠ 这两件事**互相不能替代**：`.ico` 进 PE 资源段（exe 自身的样子），PNG 走 winit
（运行期那扇窗的样子）。少了哪一个，都有一处显示成默认图标。

## 设计（自绘，无第三方素材）

**没有现成官方图标**：上游 `fluttergo/CrystalStudio`（C# + Avalonia）仓库里不含应用图标
资产（只有 Avalonia 默认窗口图标），所以本仓这一枚是按产品名自己画的
**程序化几何图形**，不含任何外部版权素材、也没有用占位图顶替。

构图（深色底 + 金色水晶 + 地图网格，与编辑器配色同调）：

* **底**：圆角方（圆角 22%），竖向渐变深海军蓝 `#0B1522 → #1C2E45`；
* **网格**：金色细线（`#FFD666`，alpha 42），落在 1/4、1/2、3/4 处 —— 代表"地图"；
* **水晶**：五面切割宝石（冠部左/右 + 亭部左/右 + 腰线/中轴棱），光从左上来：
  冠左 `#FFE28A` 最亮 → 冠右 `#F2C24B` → 亭左 `#C99A2A` → 亭右 `#7E5A12` 最暗，
  外描边 `#5A3E0C`，顶部一条 `#FFF0B8` 高光棱，左上角一枚四角星芒；
* **16 / 32 px 用简化版**：去网格、去星芒、描边加粗到 2% —— 小尺寸才不会糊成一团金块。

## 编码细节（可复算）

`.ico` 是标准 ICO：头 6 字节 + 6 个 16 字节目录项，然后按尺寸升序排数据。

* 16/32/48/64/128 五帧 = **32 位 BMP 条目**（`BITMAPINFOHEADER`，`biHeight = 2×高`，
  `biBitCount = 32`，像素 BGRA 自下而上，后接按 4 字节对齐的全 0 AND 掩码）——
  兼容性最好的老格式；
* 256 帧 = **PNG 条目**（省空间，Vista 起标配）。

`crystal-studio.png` 与 `.ico` 里的 256 帧**逐像素相同**（同一张图，同一份 LANCZOS 缩放结果）。

## 换图标怎么做

1. 覆盖这两个文件（尺寸同上；`.png` 必须还是 256×256、RGBA）；
2. `cargo build -p miredit-gui --release` —— `build.rs` 里有
   `cargo:rerun-if-changed=assets/crystal-studio.ico`，会自动重编资源并重新链接；
3. 验证（别只看窗口）：exe 的「属性 → 详细信息」里要有 `ProductName` / `ProductVersion`，
   资源管理器里要能看到这枚图标。

## 生成脚本

图标是**一次性程序化绘制**出来的（Pillow：超采样 + LANCZOS 缩放 + 手写 ICO 打包），
**产物即真源**，脚本没进仓库（它只服务于这一次出图）。需要重排几何时按上面那张参数表改即可；
脚本副本 `make_icon.py` 随本次交付一起留在交付归档里（不入库，避免给仓库添一门额外语言的工具链）。
