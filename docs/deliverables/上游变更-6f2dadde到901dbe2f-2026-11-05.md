### 3.1 `IsCrystalVersion1`（`LegacyMapReader.cs:40-41`）

**是什么**：一个纯读属性，判「这张 `.map` 是不是 CrystalStudio 自己写出的 v1 格式」。

```csharp
public bool IsCrystalVersion1 => Bytes.Length >= 8 && Bytes[0] == 1 && Bytes[1] == 0 &&
    Bytes[2] == (byte)'C' && Bytes[3] == (byte)'#';
```

- **与既有判据的关系**：`initiate()` 里已有一个**宽松**判据（新版 `LegacyMapReader.cs:62`）：`Bytes[2] == 0x43 && Bytes[3] == 0x23` —— 只认 `C#` 两个字节，**不看版本号**。新属性**额外要求 `Bytes[0..1] == 01 00`（小端 short 1）**。写侧对应 `Document.cs:83` 的 `w.Write((short)1); w.Write((byte)'C'); w.Write((byte)'#');`。

- 它只在 Sanxiu 模式下被读；我方无 Sanxiu 模式 ⇒ 无消费场景。
