## 三、约定

- 文档里的上游引用一律带 `文件:行号@提交`，可回源核对。
- 数值（字节布局、常量、阈值）以源码为唯一真值；文档与代码不一致时先修文档并记录差异。
- 已被推翻的结论不删除，就地标注「作废 + 原因 + 新结论」，避免同一条错误被子文档二次引用。
